# AtendeAI — resumo para portfólio

## Apresentação

Sou Lindomar Amarildo Quintao Olimpio, estudante de Engenharia de Software na Faculdade Anhanguera. Estou desenvolvendo o AtendeAI como projeto prático de portfólio para aprofundar meus conhecimentos em Python, desenvolvimento de APIs, testes e aplicações de Inteligência Artificial.

O AtendeAI é um protótipo de atendimento digital. Na versão 0.3.0, classifica mensagens por regras simples, consulta uma base de perguntas frequentes e combina essas informações no endpoint `/assist`, que também sinaliza quando é necessária revisão humana. O projeto está sendo construído incrementalmente, com foco em código organizado, documentação e validação por testes.

## Problema que o projeto explora

Em operações de atendimento, solicitações recorrentes — como atraso de entrega, item faltante, pagamento e cancelamento — podem exigir identificação e encaminhamento consistentes. O protótipo explora como uma API pode organizar essas mensagens e sugerir respostas iniciais.

## O que consigo demonstrar nesta versão

- Organização de um projeto Python em módulos.
- Criação de endpoints REST com FastAPI.
- Validação de dados com Pydantic.
- Manipulação de arquivos JSON.
- Normalização e comparação lexical de textos.
- Escrita de testes automatizados com Pytest.
- Documentação de arquitetura, API, limitações e roadmap.

## Tecnologias

Python, FastAPI, Pydantic, Pytest e JSON.

## Estado atual e transparência

A versão 0.3.0 não utiliza modelo de linguagem, machine learning ou RAG. A classificação e a busca são baseadas em regras e palavras coincidentes. Não há integração com sistemas reais, nem vínculo com o iFood. O projeto é inspirado em cenários genéricos de atendimento de delivery e comércio eletrônico.

## Próximo objetivo técnico

Ampliar os testes, avaliar a qualidade da classificação com exemplos variados e estudar recuperação RAG antes de considerar uma integração com LLM.
